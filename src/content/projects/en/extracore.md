Management system for the insurance industry, built from scratch on .NET Core + ASP.NET MVC. Star module: **automatic PDF e-invoice reader** using iTextSharp (table extraction), PdfPig (structure), OCR (scans) and regex (normalization). Salesforce integration via SOAP.

**Outcome:** the manual process that took ~10 min per invoice dropped to ~30 seconds automated, with cross-validation against AFIP.
